# Software — general

Shared baseline for every software spec. Spec workflows replace the general workflows for their domain.

## Rules (read on demand)

| Rule | Read when |
|:---|:---|
| `makefile-guide.md` | you change `Makefile` or `*.mk` |
| `docker-compose-guide.md` | you change compose files |
| `lint-format-guide.md` | you change linter, formatter, or pre-commit config |
| `github-workflow-guide.md` / `gitlab-ci-guide.md` | you change `.github/**` or GitLab CI |
| `readme-sync-guide.md` | you change setup, configuration, or usage that `README.md` documents |
| `git-workflow-guide.md`, `code-style-guide.md`, `sdlc-methodology-guide.md`, `sdlc-role-responsibilities.md` | a workflow or skill links them |
